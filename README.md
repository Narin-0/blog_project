📝 Django Blog App: CRUD & Permissions

Это учебное приложение на Django, реализующее систему блогов с разграничением прав доступа, кастомной Middleware и регистрацией пользователей.
🚀 Быстрый старт

Если ты только скачал проект или хочешь запустить его снова:

    Активируй окружение:
    Bash

    source venv/bin/activate

    Запусти сервер:
    Bash

    python manage.py runserver

📍 Навигация по ссылкам

После запуска сервера (http://127.0.0.1:8000/) используй следующие пути:
🏠 Основные страницы

    http://127.0.0.1:8000/ — Главная страница. Список всех постов (доступно всем).

    http://127.0.0.1:8000/post/1/ — Детали поста. Просмотр конкретного поста (доступно всем).

🔑 Авторизация и доступ

    http://127.0.0.1:8000/register/ — Регистрация. Создай нового пользователя здесь.

    http://127.0.0.1:8000/login/ — Вход. Нужно войти, чтобы создавать посты.

    http://127.0.0.1:8000/logout/ — Выход.

    http://127.0.0.1:8000/admin/ — Панель администратора. Вход под narin / 123.

✍️ Управление контентом (требуются права)

    http://127.0.0.1:8000/post/new/ — Создать пост. Только для залогиненных пользователей.

    http://127.0.0.1:8000/post/<id>/edit/ — Редактировать. Только для автора поста или админа.

    http://127.0.0.1:8000/post/<id>/delete/ — Удалить. Только для автора поста или админа.

🛠 Технические особенности

    Middleware: В консоли, где запущен сервер, ты увидишь сообщения о статусе пользователя (авторизован или аноним) при каждом обновлении страницы.

    Permissions: * Анонимы могут только читать.

        Пользователи могут создавать.

        Авторы и админ могут изменять и удалять.

    UI: Кнопки "Редактировать" и "Удалить" автоматически скрываются в шаблонах, если у тебя нет на это прав.

📂 Структура файлов

    core/ — Настройки проекта.

    posts/ — Приложение блога.

        models.py — Модель Post.

        middleware.py — Логика отслеживания статуса.

        views.py — Логика на Class-Based Views.

    templates/ — HTML-шаблоны.
